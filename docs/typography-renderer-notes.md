# Font families, sizing, and letter spacing

CSS family selection supports embedded TTF/OTF faces declared by `@font-face`, with generic `serif`, `sans-serif`, and `monospace` fallback. The selected reader face supplies the serif preference; a matched built-in sans face and a dedicated monospace face supply the other generic families. Unsupported or unreadable embedded faces fall through to the next usable family. Embedded outline faces support TrueType and CFF/CFF2 outlines, optical sizing, and available small-cap substitutions. Font extraction and face caches are bounded.

SD font selection preserves upstream native TTF families, lazy native pixel sizes, and the persistent glyph store. HD `.cpfont` v5/v6 faces and embedded outline faces rasterize at twice their displayed size; native SD TTF faces retain their upstream raster scale. Logical point-size metadata keeps publisher optical sizing independent of raster density. Publisher face IDs occupy a reserved namespace that SD hashes and native size windows avoid. Native SD TTF retains synthetic small caps; embedded outlines and v6 converted fonts can use authored `smcp`/`c2sc` substitutions. HD conversion rejects kerning tables exceeding 255 classes rather than approximating their adjustments; legacy v4 conversion retains upstream class reduction.

A word carries one compact family/spacing annotation through layout, hyphenation, bionic splitting and table retries. Uniform lines store one scalar; mixed lines store an optional aligned annotation array in the existing arena. Tracking is computed at the declaration and inherited as an absolute length. The same glyph walk measures and draws text, disables optional ligatures under nonzero tracking, preserves combining marks and uses the rasterizer's bearing convention. Table cells persist their actual line advance. Prewarming remains a scan without glyph-width measurement and respects the four built-in cache slots.

Synthetic EPUB cases cover family switches, bold/italic inline spans, nested inheritance, table cells, positive/negative tracking, resets, different-size inherited tracking, joined runs and long words. Mixed-family floated drop caps fall back to enlarged inline runs so distinct quote/letter formatting is preserved; inline size retains the renderer's existing 250% cap.

Float exclusion now uses exact line indices from the greedy breaker for paragraphs containing floats. A single pass computes resolved run-height bounds: uniform families get exact geometry, while mixed-family lines use conservative cumulative bounds so text cannot enter an image. A mixed paragraph may remain narrow slightly longer than an exact line-by-line browser layout. Paragraphs without floats retain the existing dynamic-programming breaker.

Blank separators capture their own resolved family height and CSS spacing when created, so the next element's family cannot change the pending gap. Case transforms, expanding Unicode, and streaming boundaries preserve typography and source-position metadata.

The local production renderer harness in `test/real_renderer` uses the actual font decoder and glyph drawing code. It checks all four faces of both built-in families, small caps, scaling, and signed tracking, and exports a PNG. The optional local `.cpfont` fixture also checks SD font bitmaps and grayscale-plane output. Reduced glyphs use area coverage so 75% uppercase text and small caps retain thin strokes. Physical panel behavior, refresh-waveform appearance, and complete UI behavior require device verification.

Existing golden changes retain identical word sequences; newly honored family annotations and consistent scaled word-gap measurement account for the differences. The extended typography fixture adds new synthetic content.
