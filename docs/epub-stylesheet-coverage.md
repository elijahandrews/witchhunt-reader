The reader filters linked stylesheets and document-local `<style>` blocks by their media type. A stylesheet linked only for another device, such as `amzn-mobi`, `print`, or `speech`, no longer overrides screen styles. Empty media, `screen`, `all`, comma-separated alternatives, `only`, and simple `not` qualifiers are handled case-insensitively. Unreferenced stylesheets retain the existing compatibility fallback. A shared stylesheet used by any applicable spine document stays enabled.

This is a conservative media-type filter. Viewport-dependent conditions remain unresolved, and external stylesheets still share the book-wide cascade. It does not implement general media queries or per-document external stylesheet ordering. An incomplete or truncated head inventory keeps the previous merge behavior rather than incorrectly excluding a potentially applicable stylesheet. Transient read or memory failures also schedule a new inventory on the next open.

Body margins and padding now use the same container layout as nested blocks. Horizontal insets compose once with child insets and the reader's outer viewport. Small images opening a left-aligned or justified paragraph can share its first text line, including paragraphs with hanging indents. Marker images move with their text across a page break and keep the following words' source anchors. Larger illustrations and centered image paragraphs retain block layout.

Existing search and long-paragraph navigation specimens remain unchanged. Host tests use original synthetic content and validate warm-cache reload, incomplete heads, page layout, image placement, and source-anchor relocation.
